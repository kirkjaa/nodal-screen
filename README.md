# NODAL Screen

Portable 3D movement screening with NODAL M1 cameras: a short walking and balance protocol, a gait report against age and sex norms, flags a clinician reviews, and a suggested pathway (a Well-Child Visit developmental review or an adult screening pathway). NODAL's entry to the Future Health Challenge (Abu Dhabi), preventive screening statement. It screens and flags; it does not diagnose. All data in this repository is synthetic.

Status: in development, prototype due 20 November 2026. The workplace version, Strain Watch, is in `sw/` and `web/report.html`; its original description follows.

## Strain Watch

Early warning for work-related strain injury from markerless 3D motion, built on NODAL M1 cameras.
